# Reviewed UI previews

`input-preview.png` and `success-preview.png` are authentic native Glint view
renderings reviewed for visual content and metadata. They contain no user documents
or queries. The input preview predates the current panel mark; README captions this
difference rather than presenting it as an exact current-release rendering.

Settings imagery is intentionally omitted because it can expose a personal
executable path. The debug smoke harness tests Settings rendering but does not
export it. Do not copy images from `build/` wholesale.

Future documentation captures need visual **and** metadata review before inclusion.

`badges/` contains local static SVG labels for the documented macOS requirement,
Swift language version, and MIT license. They are not live build/release status
indicators and contain no external resources or scripts.
